# minipi 快速上手

## 这是什么

一个常驻桌面的 AI 悬浮球。选中一段文字按快捷键，它直接接着问；平时就在屏幕边缘待着，不挡事。

**会话、产出、密钥全部留在你自己的电脑上**，不经过我们的服务器。详见 [PRIVACY.md](./PRIVACY.md)。

---

## 一、安装

### Windows

1. 双击 `minipi Setup 1.0.0.exe`。
2. 安装程序会让你选安装位置。默认装在当前用户目录下，**不需要管理员权限**，不会弹 UAC。
3. 装完桌面和开始菜单会有快捷方式。

> 首次双击时 Windows 可能弹「已保护你的电脑」。这是因为安装包**没有买代码签名证书**（个人项目，证书年费不便宜）。点「更多信息」→「仍要运行」即可。

### macOS

1. 打开 `minipi-1.0.0.dmg`，把 minipi 拖进「应用程序」。
2. 第一次打开会被 Gatekeeper 拦住（原因同上：未签名）。**右键点图标 → 打开 → 再点「打开」**，之后就正常了。
3. 如果提示「无法验证开发者」，去「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」。

## 二、第一次使用：配一个模型

minipi 自己不带模型，需要你填一个模型服务的 API Key。**只需配一次。**

启动后如果右下角/屏幕边缘出现「还没有配置模型」的引导卡：

1. 点卡片上的「去配置」（或点悬浮球右键 → 模型设置）。
2. 在「模型设置」里选一个提供方。下面以 DeepSeek 为例：

   | 字段 | 填什么 |
   |---|---|
   | 提供方 | `deepseek` |
   | API 地址 | `https://api.deepseek.com` |
   | API Key | 你在 DeepSeek 开放平台申请的 key（`sk-` 开头） |
   | 模型 | 点「拉取模型」自动获取，或手填 `deepseek-chat` |

3. 保存后选一个模型作为默认。

配好之后，悬浮球就能用了。

> **Key 存在哪？** `~/.minipi/credentials.json`，文件权限设为仅当前用户可读。界面上**不会回显**已保存的 key，也不会写进日志。

## 三、三个操作

| 操作 | 快捷键 |
|---|---|
| 唤起 / 收起 | `Alt` + `Space` |
| 抓当前选中的文字并直接提问 | `Alt` + `Shift` + `Space` |
| 开关悬浮球 | 悬浮球上右键 → 菜单 |

macOS 上把 `Alt` 换成 `Option`。

**悬浮球可以拖动**：按住整个球往任意方向拖，松手后会自动吸附到最近的屏幕边缘。想让它半隐藏，把球拖到边缘停一会儿。

> 快捷键被别的软件占用时，minipi 会在日志里记一条注册失败。换一个不冲突的键位，或者先关掉占用的软件。

## 四、数据存在哪

全部在 `~/.minipi/` 下：

```
~/.minipi/
├── settings.json        设置（主题、场景、窗口位置等）
├── credentials.json     API Key（权限 0600）
├── providers.json       自定义提供方定义
├── sessions/            会话正文与索引
├── outbox/              随手产出的文件（你说「导出」时生成的东西）
├── approvals-audit.log  审批记录（哪个文件被允许写入了）
└── logs/
    ├── main.log         程序本体日志
    └── launcher.log     启动器日志（仅开发/源码启动时有）
```

**这个目录就是你的全部数据。** 想备份，整个拷走；想换机器，整个拷过去。

## 五、出问题了怎么反馈

minipi 的日志在 `~/.minipi/logs/`。

反馈时请附上：

1. **`main.log`** —— 程序本体日志，绝大多数问题看这个。
2. 你的操作系统版本（如 Windows 11 23H2）。
3. 具体现象：什么时候、点了什么、期望什么、实际什么。

日志里可能有你的文件路径和会话标题。发送前可以先打开看一眼，介意就删掉那几行。

## 六、卸载与备份

### 卸载

Windows：设置 → 应用 → minipi → 卸载。
macOS：把 minipi 从「应用程序」拖到废纸篓。

**卸载程序不会删 `~/.minipi/`。** 这是刻意的：里面是你的会话和密钥，卸载时顺手删掉属于数据丢失，不属于清理。

### 彻底清除

确认不需要历史会话后，手动删除整个目录：

```powershell
# Windows PowerShell
Remove-Item -Recurse -Force "$env:USERPROFILE\.minipi"
```

```bash
# macOS
rm -rf ~/.minipi
```

### 备份

```powershell
# Windows：拷到 D 盘
Copy-Item -Recurse "$env:USERPROFILE\.minipi" "D:\minipi-backup"
```

```bash
# macOS
cp -R ~/.minipi ~/minipi-backup
```

## 七、常见问题

**Q：双击没反应，球也不出现。**
先看 `~/.minipi/logs/main.log` 的最后几行。如果文件不存在，说明程序在写日志之前就退出了——把操作系统版本告诉我们，这本身就是一个 bug。

**Q：球出现了，但发消息没反应 / 提示模型不可用。**
多半是 key 没配好或余额不足。打开「模型设置」，重新填一次 key，点「拉取模型」确认能连上。

**Q：`Alt+Space` 按了没反应。**
这个组合键常被输入法或窗口管理工具占用。看 `main.log` 里有没有「注册失败」，换一个键位。

**Q：透明背景变成黑色方块。**
这是显卡驱动的问题。minipi 已经关掉了 GPU 沙箱来规避大部分情况；如果还出现，更新显卡驱动，或在启动时加环境变量 `MINIPI_KEEP_GPU_SANDBOX=0` 后重试。

**Q：能不能多开？**
不能。重复启动会唤起已有窗口，不会起第二个进程。这是设计如此——避免多个球抢热键。
