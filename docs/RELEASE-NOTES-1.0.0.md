# minipi 1.0.0

首个对外发布版本。常驻桌面的 AI 悬浮球：选中一段文字按快捷键就能问，平时待在屏幕边缘不挡事。**会话、产出与密钥全部留在本机。**

---

## 这版能做什么

| 能力 | 说明 |
|---|---|
| 悬浮球三态 | 球 / 小窗 / 大窗，可拖动、自动吸附屏幕边缘、半隐藏 |
| 选中即问 | `Alt+Shift+Space` 抓当前选中文字直接提问 |
| 全局唤起 | `Alt+Space` 开合窗口（macOS 为 `Option`） |
| 会话管理 | 自建存储（`~/.minipi/sessions/`），支持搜索 / 置顶 / 归档 / 改名 / 删除（进回收站） |
| 会话恢复 | 从列表恢复历史会话，模型上下文一并还原（不是「装作记得」） |
| 审批闸门 | 需要写文件时弹审批卡，四档：允许一次 / 本会话允许此文件 / 拒绝并说明 / 中断整轮 |
| 产出抽屉 | 随手产出落 `~/.minipi/outbox/`，支持导出 md / docx |
| 模型配置 | 内置提供方卡片 + 自定义提供方（自带 API 地址与模型目录） |
| 联网能力 | 可选联网搜索 / 抓取，用你自己的 Key |
| 系统托盘 | **本版新增**：常驻托盘，单击显示/收起，右键菜单可唤回窗口 |

## 本版重点修复

### 打包版没有任何日志（发布阻断级）

1.0 之前，主进程日志依赖启动器把子进程 stdout 重定向到文件。打包后没有启动器，而 Windows 的 GUI 子系统程序没有控制台 —— `console` 输出被系统直接丢弃。**后果是客户报「双击没反应」时，我们手上零信息。**

现在主进程自己同步落盘 `~/.minipi/logs/main.log`（超 1MB 轮转 `.old`）。日志写入失败**绝不影响启动**。

### 崩溃时没有任何提示

主进程崩溃后，用户看到的是「悬浮球突然消失了」，既不知道发生了什么，也不知道该把什么发给开发者。

现在未捕获异常会弹一个系统对话框，写明日志的**绝对路径**与错误摘要。只弹一次（连续崩溃不会弹满一屏），弹窗本身出错也不会二次崩溃。

### 首次启动不知道要配模型

错误文案曾写「需 `~/.pi/agent/auth.json` 里至少一个可用 provider」—— 那是另一个工具的目录，客户机上根本不存在。

现在：没有可用模型时，聊天区会出现一张引导卡，一句话说明原因 + 一个「去配置」按钮（打开模型设置）+ 一行「Key 只保存在本机」。文案改为「请点『模型设置』填入 API Key 并选择一个模型」。

### 安装目录

安装时选任意目录（例如 `E:\`），实际会装到其下的 `minipi` 子目录（`E:\minipi`），不再把 `minipi.exe`、`resources\`、`locales\` 直接铺到盘符根目录。

## 安装

### Windows

1. 下载 `minipi Setup 1.0.0.exe`（约 116 MB），双击。
2. 可选安装目录，默认装在当前用户目录下，**不需要管理员权限**。
3. 首次运行 Windows 可能提示「已保护你的电脑」—— 安装包**未做代码签名**（个人项目，证书年费不便宜）。点「更多信息」→「仍要运行」。

### 第一次使用

minipi 不带模型，需要你填一个模型服务的 API Key，**只需配一次**：

1. 启动后点引导卡的「去配置」（或悬浮球右键 → 模型设置）。
2. 选提供方，例如 DeepSeek：API 地址 `https://api.deepseek.com`，填入 `sk-` 开头的 Key，点「拉取模型」，选 `deepseek-chat`。
3. 保存。

详细步骤见 [docs/QUICKSTART.md](docs/QUICKSTART.md)。

## 数据与隐私

全部数据在 `~/.minipi/`，不上传、不收集遥测、不做崩溃上报。

联网只有三种情形，且都由你的操作触发：调用你自己配置的模型 API、你主动点「联网搜索」、你点「拉取模型」。

API Key 存在 `~/.minipi/credentials.json`（权限 `0600`），**界面不回显、不回传渲染层、不进日志**。

详见 [docs/PRIVACY.md](docs/PRIVACY.md)。

## 验证情况

- 回归门禁 **35 个脚本全绿**（含 headless Chrome UI 断言、纯 Node 单元断言、真实 Electron 启动自测）
- 打包产物验证 **21/21**：asar 内容、必需文件、`main` 指向、真启动（存活 ≥6s + OS 窗口句柄 > 0）
- 关键门禁做过**变异验证**：把实现改坏，断言必须变红，再逐字节还原 —— 没红过的断言不算守护

**未覆盖**：真机安装向导、透明窗口/DWM 合成的人眼观感、macOS 实机。
